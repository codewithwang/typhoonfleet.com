The names stay in the room. The text can leave.

Haze replaces names and numbers with stand-ins before text leaves the machine that holds it, drops anything it cannot make safe, and can make everything it ever sent unreadable. It is a fleet service, not something you call: it sits at the wall and protects what goes out. It is built and runs on one internal workload.

What Haze carries.

Three pieces of kit, all built. In security terms this is the masking half of data loss prevention: it acts before the data leaves, instead of alerting after.

How it works.

Everything up to the seal happens on the machine that holds the real data.

Learn the names

Haze builds a dictionary from the source itself. Each organisation gets a stand-in such as Client-A or Vendor-1, and it is the same stand-in every time, so a reader can still follow a thread. The table that maps them back stays on the source.

Mask

Fixed rules do most of the work: surnames go, first names stay with a role beside them, and amounts, phone numbers, email addresses, links, network addresses and reference codes are replaced. A small AI model, running on the same machine, is used only to find names the rules missed.

Gate

Every record is checked again by rules alone, with no model involved. If anything on the sensitive list is still there, the record is dropped.

Seal

What passes is encrypted to the recipient's public key (X25519 and ChaCha20-Poly1305) before it travels. Only the holder of the private key can open it.

The kill switch is one command: it deletes the private key, wipes the opened copies, and tells the source to wipe its dictionary and its outbox.

What it does, and where it falls short.

It does

  • Keep stand-ins stable, so masked text still reads as a coherent thread.
  • Prefer dropping a record to sending a doubtful one. On its first real batch the gate dropped 51 records; after the rules were corrected it dropped 2.
  • Keep the real-name table on the source machine only.
  • Make every batch unreadable by deleting one key.

It does not

  • Anonymise. Masked text still carries what was asked, the tone, and the shape of the relationship. Someone who knows the context may still recognise it.
  • Have a measured miss rate. Spot checks have found misses, and each was fixed with a new rule. That is not a measurement.
  • Catch every company name. A name with no legal ending (Limited, Inc, Group) that the model also misses will get through.
  • Work on anything but its first source. There is one adapter.
  • Block or watch channels. It masks what is handed to it; it does not sit on the network looking for leaks.
  • Run for you. It is a service inside the fleet.
